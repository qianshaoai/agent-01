## 实施清单

### Phase 0a · isTagAdmin helper（R1.2-2 收口）

[lib/admin-permissions.ts](../../lib/admin-permissions.ts) 追加：

```ts
export function isTagAdmin(role: AdminRole | null | undefined): boolean {
  return role === "super_admin" || role === "system_admin";
}
```

签名与现有 `canActOnRole` / `roleLabel` / `noWritePermissionMessage` 统一（直接收 `AdminRole | null | undefined`），调用方一致。

### Phase 0b · 10 个 API endpoint isTagAdmin 拦截（R1.1-4 + R1.2-1）

| # | Endpoint | 改动 |
|---|---|---|
| 1 | `POST /api/admin/categories` | + isTagAdmin |
| 2 | `PATCH /api/admin/categories/[id]` | + isTagAdmin |
| 3 | `POST /api/admin/categories/[id]/icon` | 改 hardcode `role === "org_admin"` → `isTagAdmin` |

- 不变：GET / 列表 / 读详情 endpoints 不拦（只读全管理员可见）
