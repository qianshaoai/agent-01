## 编辑用户消息内联 textarea 放大一档

### 触发

用户在工作流页面用「编辑用户消息」功能时反馈「这个编辑功能很好，但是太小了」。

### 改动 · 1 文件 1 处

改 [`app/agents/[id]/page.tsx:225-258`](../../app/agents/[id]/page.tsx) 编辑用户消息
内联 textarea 容器，整体放大一档：

| 维度 | 改前 | 改后 |
|---|---|---|
| 容器最小宽度 | `min-w-[260px]` | `min-w-[360px]`（+100px）|
| textarea 字号 | `text-[14px]` | `text-[15px]`（+1px）|
| textarea 行数 | 2-8 行 | 3-10 行（初始 +1，上限 +2）|
| 按钮字号 | `text-[11px]` | `text-[12px]`（+1px）|
| 按钮 padding | `px-2 py-1` | `px-3 py-1.5`（横向 +4px、纵向 +2px）|

代码：

```tsx
// 改前
<div className="flex flex-col gap-2 min-w-[260px]">
  <textarea
    rows={Math.min(8, Math.max(2, editValue.split("\n").length))}
    className="... text-[14px] ..."
  />
  <button className="text-[11px] px-2 py-1 ...">取消</button>
  <button className="text-[11px] px-2 py-1 ...">保存并重发</button>
</div>

// 改后
<div className="flex flex-col gap-2 min-w-[360px]">
  <textarea
    rows={Math.min(10, Math.max(3, editValue.split("\n").length))}
    className="... text-[15px] ..."
  />
  <button className="text-[12px] px-3 py-1.5 ...">取消</button>
  <button className="text-[12px] px-3 py-1.5 ...">保存并重发</button>
</div>
```

### 不动的部分

- 容器圆角、颜色、resize 行为不变
- 按钮位置（右下角、gap-1.5）不变
- ESC 关闭、autoFocus、onSave / onCancel 回调逻辑不变
- 只影响 `app/agents/[id]/page.tsx` —— `app/trial/page.tsx` 的「保存并重发」是
  另一处试用页编辑器，本次不动（如需对齐另议）

### 验证

dev server 热重载后，在工作流页面任意用户消息点「编辑」按钮，确认 textarea +
按钮整体变大；行数自适应（短消息 3 行起、长消息上限 10 行）。

### 后续可选

- 若仍嫌小，可继续放大到 `min-w-[440px]` + `text-[16px]`
- `app/trial/page.tsx` 的同款编辑器如需对齐再开一单

## 第二轮 · 编辑器高度自适应 + 550px 封顶（不出滚轮）

### 触发

用户反馈「编辑器如果字数超出界面不做滚轮，而是放大，因为这个做滚轮意义不大」。
原 `rows={Math.min(10, Math.max(3, editValue.split("\n").length))}` 只看硬换行
`\n` 数、且 10 行硬封顶——长文本（尤其软换行的长段落）会出滚轮，编辑体验差。

### 改动 · 同文件 2 处

文件 [`app/agents/[id]/page.tsx`](../../app/agents/[id]/page.tsx)：

**改动 1 · import 加 `useLayoutEffect`**（line 2）

```ts
import { useState, useRef, useEffect, useLayoutEffect, use, memo, Fragment } from "react";
```

**改动 2 · ChatMessage 组件加 editTextareaRef + useLayoutEffect**

```tsx
const editTextareaRef = useRef<HTMLTextAreaElement | null>(null);
useLayoutEffect(() => {
  if (!isEditing) return;
  const el = editTextareaRef.current;
  if (!el) return;
  el.style.height = "auto";
  const target = Math.min(el.scrollHeight, 550);
  el.style.height = `${target}px`;
  el.style.overflowY = el.scrollHeight > 550 ? "auto" : "hidden";
}, [editValue, isEditing]);
```

**改动 3 · textarea 加 ref + 改 rows**

```tsx
<textarea
  ref={editTextareaRef}
  // ...
  rows={3}  // 改前 rows={Math.min(10, Math.max(3, editValue.split("\n").length))}
/>
```

### 效果

- ≤ 550px（约 28 行）：textarea 高度跟内容实时同步、**无滚轮**（overflow-hidden）
- > 550px：高度封顶 550px、**出滚轮兜底**（overflow-y-auto），防极端长文本顶屏
- 硬换行 `\n` 和软换行（一行超长自动折行）**都生效**——直接读 scrollHeight，不再靠 `\n` 数估算
- 切换 isEditing 进入编辑态时立即跑一次（mount + deps 触发）

### 不动的部分

- min-w-[360px] / text-[15px] / 按钮 px-3 py-1.5 + text-[12px] 第一轮放大全部保留
- `app/trial/page.tsx` 同款编辑器不动（如需对齐再开一单）
- resize-none（禁用户手动拖拽）保留

### 验证

dev 热重载后：
1. 任意工作流消息「编辑」→ 短消息从 3 行起、键入到第 4 行自动撑开
2. 粘贴一段长文本 → 编辑器自动撑到 550px 高度，开始出滚轮
3. 粘贴超长文本（>550px）→ 高度封顶 550px、内部可滚

### 后续微调

- 用户口味调整：封顶值 600 → 550（约 28 行），略矮一点更适合工作流编辑场景。本节
  上述所有数值已对齐 550 为最终值。
