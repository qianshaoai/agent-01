## 背景

`app/admin/agents/page.tsx` 的「API 配置」弹窗历来用一个 JSON textarea 让 admin
填 `modelParams`（默认 `{"temperature": 0.7, "max_tokens": 2000}`）。
非技术 admin 不会写 JSON，coze 智能体绑定时要手写 `{"bot_id": "..."}`，拼错 / 漏引号 /
多逗号都会让保存失败。本期把这个 textarea 换成按 effectivePlatform 渲染的 input 列表
+ 折叠 JSON 折叠。

## 实施清单

### Phase 0 · 新建 `lib/platform-param-schema.ts`

平台 → ParamField[] 映射 + 校验 helper。

- `ParamField`：`{ key, label, type: "text"|"number"|"password", required?, placeholder?, hint?, min?, max?, step? }`
- `PlatformSchema`：`{ fields, noFieldsHint?, hideJsonIfEmpty? }`
- `schemaForPlatform(platform)` 覆盖：
  - **coze** · `bot_id` (text, required)
  - **yuanqi** · `assistant_id` (text, required)
  - **qingyan** · `assistant_id` (text, required) + `api_secret` (password, required)
  - **dify** · 无 fields；`hideJsonIfEmpty: true`（advancedJson 空时连折叠都隐藏）
  - **openai / anthropic** · `model` (text) + `temperature` (number, 0~2) + `max_tokens` (number, 1~128000)
  - **zhipu** · `model` + `temperature` (0~1) + `max_tokens`
  - **other** · 无 fields + noFieldsHint「请用『高级（JSON）』维护」
  - **default** · 同 other，message 动态拼平台名
- `parseAdvancedJson(raw)`：必须解析为 `Record<string, unknown>`，array / null / 标量都 `{ ok: false, msg }`
- `validateNumberField(f, raw)`：留空返回 `NaN`（外层 `Number.isFinite` 过滤）；非数字 / 越界都阻塞

### Phase 1 · 改 `app/admin/agents/page.tsx`

#### 状态形态变更

```diff
- const EMPTY_API = { modelParams: '{"temperature": 0.7, "max_tokens": 2000}', providerId: "" };
+ type ApiFormState = {
+   providerId: string;
+   inputs: Record<string, string>;
+   advancedJson: string;
+   advancedOpen: boolean;
+ };
+ const EMPTY_API: ApiFormState = { providerId: "", inputs: {}, advancedJson: "", advancedOpen: false };
```

加 `prevEffPlatRef: useRef<string | null>(null)` 跟踪上一次 effectivePlatform。

新增内部 helper：
- `splitParamsBySchema(params, schema)`：按 schema key 分流出 inputs（属于 schema）+ advancedJson（不属于）
- `collectCurrentParams(form, schema)`：把当前 form 状态收回成一份完整 `Record<string, unknown>`（用于 re-split）

#### `openApi(a)`

- `initialPlatform = resolveEffectivePlatform(a.provider_id ?? "", [], a)`（首次分流不依赖 apiProviders 异步结果；仅原绑定 provider 可用 `agent.provider.platform` 兜底）
- `splitParamsBySchema(a.model_params ?? {}, schemaForPlatform(initialPlatform))` 设进 inputs / advancedJson
- `advancedOpen: false`（决策点 3 · 默认收起）
- `prevEffPlatRef.current = initialPlatform`

#### Re-split useEffect

```ts
useEffect(() => {
  if (!showApiModal) { prevEffPlatRef.current = null; return; }
  const effPlat = resolveEffectivePlatform(apiForm.providerId, apiProviders, showApiModal);
  if (prevEffPlatRef.current === effPlat) return;
  // effPlat 变了 → re-split
}, [showApiModal, apiForm.providerId, apiProviders]);
```

- 触发场景：用户切下拉、apiProviders 异步加载完成、关弹窗
- `prevEffPlatRef.current === null` 时表示是首次（openApi 已分流），跳过避免覆盖
- `collectCurrentParams(apiForm, oldSchema)` 收当前所有参数 → 新 schema 重做分流：
  - 通用 key（如 `model` / `temperature`）继续留在新 inputs
  - 平台专属 key（如 `bot_id`）变成新 schema 的「非 schema」→ 进 advancedJson，不静默丢弃
- 验收修正：providerId 切到「未绑定」时必须回退 `agent.platform`，不能继续沿用旧 `agent.provider.platform`

#### `handleSaveApi()`

```diff
- let params = {};
- try { params = JSON.parse(apiForm.modelParams); } catch {}
+ const effPlat = ...;
+ const schema = schemaForPlatform(effPlat);
+ const adv = parseAdvancedJson(apiForm.advancedJson);
+ if (!adv.ok) { toast(adv.msg); return; }
+ const inputParams = {};
+ for (const f of schema.fields) {
+   if (f.type === "number") {
+     const r = validateNumberField(f, raw);
+     if (!r.ok) { toast(r.msg); return; }
+     if (Number.isFinite(r.value)) inputParams[f.key] = r.value;
+   } else if (raw !== "") inputParams[f.key] = raw;
+ }
+ // required 校验
+ // input 优先合并：finalParams = { ...adv.value, ...inputParams }
```

提交时 `modelParams: finalParams`（替换原 `params`）。

#### UI · 替换原 textarea

原来单行 textarea（line 898 in master2），现在拆成：

1. **「模型参数」标题行** + 「按平台 {effPlat}」小字
2. **schema.fields.length === 0 && schema.noFieldsHint** → 灰底提示卡
3. **schema.fields.map** → 渲染对应 input
   - `type=password` 用密码框（qingyan api_secret）
   - `type=number` 带 min/max/step
   - hint 在 input 下方小字
   - required 字段标红 `*`
4. **高级（JSON）折叠**：
   - dify + advancedJson 空 → 隐藏（决策点 1）；非空时显示 + 「· 已保留旧参数」标记
   - 其它平台始终显示折叠按钮
   - 默认收起，点击展开 textarea
   - 「同名 key 时 input 值优先」提示

## 人工待跑（dev 实测）

按方案 E 节 8 项：

1. coze 智能体 → API 配置 → 显示「Bot ID」input + 高级折叠（收起）→ 填 bot_id 保存 → DB 存 `{"bot_id":"..."}`
2. yuanqi → 显示「Assistant ID」input
3. qingyan → 显示「Assistant ID」+「API Secret」（密码框）两个 input
4. dify → 显示「无需额外配置」提示、不显示 input；advancedJson 空则隐藏 JSON 折叠
5. 老数据兼容：用现有有 modelParams 的 coze 智能体打开弹窗 → input 自动填值
6. 高级 JSON 填 `{"custom_x":1}` + input 填 bot_id → 保存后 DB 包含两个字段
7. provider 切换：同弹窗从 coze 切到 qingyan → 字段按 qingyan 显示，bot_id 进高级 JSON 不静默丢弃
8. 校验失败：非对象 JSON / 语法错误 / number 越界或 NaN → toast 提示且不提交 PATCH
