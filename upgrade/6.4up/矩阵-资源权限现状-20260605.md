## 用法

- 本表是**唯一 source of truth**：v52 seed SQL、各 adapter 的 listFilter/checkRead/checkWrite、UI Tab 1/2 默认值全从此矩阵派生
- 每一行对应一个 `permission_key`；列含义：
  - `resource` / `action` / `scope`：构成 key `<resource>.<action>.<scope>`
  - `current_routes`：现状代码命中此 (resource, action) 的 admin 路由
  - `current_allowed_roles`：现状代码允许哪些 builtin role 操作（审计来源 = grep + 源码阅读）
  - `structural_constraint`：结构性约束（adapter checkWrite 内必须复刻，不靠 permission_key 覆盖）
  - `proposed_role_seed`：v52 `builtin_role_permissions` 表的初始 seed（与 current_allowed_roles 等价 → 零默默放权）
